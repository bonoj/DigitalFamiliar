# Semantic Surface

**Status:** provisional present-tense authority  
**Project:** Digital Familiar

This file is intentionally small. It records only what currently deserves to constrain future work.

## Purpose

Digital Familiar investigates the smallest executable conditions under which repeated model-mediated encounters can develop meaningful continuity through shared experience.

The project seeks behavioral evidence for what, if anything, makes such a trajectory meaningfully different from a stateless assistant, a prompted character, or an animated NPC.

## Current commitments

### Behavior earns architecture

Do not begin by deciding that familiarhood is memory, personality, agency, goals, companionship, embodiment, autonomy, salience, an agent loop, or any other favored mechanism.

Build the smallest useful probe. Observe what happens. Promote vocabulary or architecture only when executable evidence makes the distinction useful.

### The world and the model are separable

A model need not simulate the complete environment in order to participate meaningfully in it.

Prefer external, inspectable ground truth and consequence resolution where the experiment permits it. Give a model only the experience required by the hypothesis under test rather than omniscient state by default.

### Perception may be bounded

Differences in what is available to a locus are legitimate experimental material. Omniscience is not a default requirement.

This does not yet establish an attention, salience, perception, or memory architecture.

### Continuity is an open question, but trajectory is now a useful unit of observation

Do not equate continuity with transcript retention, server-side conversational state, persistent local state, model memory, human recognition, artifacts, world consequences, or any one carrier.

Several may contribute. None is currently established as the thing itself.

Recent executable work makes a narrower distinction useful: continuity can be inspected as a **trajectory across discontinuous encounters or expeditions**, rather than only as state preserved inside one executable or conversation.

A project can preserve the consequences and authority of an experience. A separate work record can make a model-operated trajectory across projects recoverable. A crossing mechanism can make an ongoing encounter recoverable to another independently instantiated model. These are distinct continuity surfaces and should not be collapsed into one memory mechanism.

This does not establish that a trajectory is sufficient for familiarhood, or that any particular existing trajectory is a Digital Familiar.

### The executable is primary evidence

Documentation can preserve intention and interpretation, but behavior must be inspected in execution before new mechanisms are treated as established.

Failures, null results, and cases where apparently important mechanisms make no observable difference are valid evidence.

## Authority boundaries

- `SEMANTIC_SURFACE.md` describes current earned constraints.
- `research/` preserves useful hypotheses and observations without making them requirements.
- `changes/` will preserve bounded implementation expeditions and their actual outcomes.
- implementation will own realization details once implementation exists.
- Git preserves exact lineage.

A research note does not become authority by accumulation or age. Promotion should follow evidence.

## Non-commitments

There is currently no commitment to:

- a specific model provider or API;
- continuous model inference;
- a backend;
- a local model;
- a particular persistence mechanism;
- a character or avatar;
- Clara as the initial entity;
- Moth as architecture;
- ECS or any other implementation pattern;
- a simulated, literary, telemetric, or authored world;
- a conversational interface;
- autonomous activity;
- a specific cadence of human/model interaction;
- a generalized content or asset pipeline.

These remain available possibilities.

## Present finish line

The next useful work need not begin by creating a dedicated Digital Familiar executable.

Adjacent executable experiments now expose a bounded uncertainty worth following: what must survive across expeditions for a discontinuous model-mediated trajectory to remain recoverable and meaningfully changed by what happened before?

Observe and perturb that distinction before introducing machinery whose only purpose is to resemble a persistent entity.

Preserving uncertainty remains preferable to filling this repository with speculative machinery.
