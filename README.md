# Digital Familiar

Executable research into persistent model-mediated entities, shared experience, continuity, attention, and emergent familiarhood.

## Research question

What is the smallest executable environment in which a model-mediated locus can share experience with a human long enough to become meaningfully different from a stateless assistant or an animated NPC?

This repository does not assume the answer is memory, personality, goals, agency, embodiment, companionship, autonomous action, an agent architecture, or any particular model or world substrate.

The working discipline is simpler:

> Let executable behavior earn vocabulary and architecture.

The project is intentionally broader than any current mechanism hypothesis. **Digital Familiar** names the phenomenon under investigation, not a proposed implementation.

## Method

The recurring research loop is:

**human intention → smallest useful executable hypothesis → shared/spatial experience → perceptual and behavioral evidence → inspection → correction → repeated evidence → semantic or architectural promotion where earned → next hypothesis**

Executable behavior is primary evidence. Failure is useful when it is cheap, visible, and diagnostic. A convincing explanation is not a substitute for an observed mechanism.

The model does not need to simulate the whole world. Where possible, deterministic machinery should own exact ground truth and consequence resolution while the model inhabits a bounded epistemic position.

## Repository surfaces

- `SEMANTIC_SURFACE.md` — the small amount of present-tense semantic truth this project currently claims.
- `research/` — observations, hypotheses, antecedent evidence, and questions worth preserving without granting them authority.
- `changes/` — bounded expeditions once implementation begins: intended question, evidence sought, actual outcome, and resulting promotions if any.
- executable artifacts — primary behavioral evidence once they exist.
- Git history — exact implementation and semantic lineage.

Research notes are deliberately non-authoritative. Their presence does not constrain ordinary implementation.

## Lineage

This project inherits a research practice, not an implementation fork.

The distinction between semantic authority, provisional research, change archaeology, executable evidence, and Git lineage was developed through the [World Lab](https://github.com/bonoj/world-lab) work. The originating research remains there rather than being copied here. Digital Familiar may reference prior evidence, test related hypotheses independently, and earn different conclusions.

Earlier experiments including Moth, Livesey, Clara, tactical play, embodied laboratories, and shared-world apparatus inform the questions recorded here. They are antecedent evidence, not requirements.

## Current state

Digital Familiar still has no dedicated executable of its own. That absence is no longer equivalent to having no executable evidence.

Astra now provides a live adjacent probe of continuity across expeditions: discontinuous model-operated runs can orient from a persistent work record, enter project repositories with their own authority and evidence, perform new work, and leave consequences available to later runs. AstralBridge separately probes continuity across an encounter with an independently instantiated model.

These are evidence-bearing neighboring experiments, not yet Digital Familiar architecture.

The immediate task is to inspect what these trajectories actually preserve, lose, compress, and change before inventing a dedicated familiar runtime merely to make the project feel implemented.
